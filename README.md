## Project Description

The Movie Theatre Ticket and Waiting Queue System is a console-based Java application that manages movie details, ticket bookings, seat availability, ticket cancellations, and customer waiting lists.

The project demonstrates the use of arrays and the First-In-First-Out (FIFO) queue data structure.

## Features

- Add and display movie details
- Check available seats
- Book movie tickets
- Assign seat numbers
- Cancel tickets
- Add customers to the waiting queue when seats are full
- Assign a cancelled seat to the first customer in the waiting queue
- Display bookings and waiting lists

## Data Structures Used

**Arrays:** Store movie information, seat numbers, and booking details.

**Circular Queue:** Stores waiting customers and follows the FIFO principle.

## Requirements

- Java JDK 8 or later
- Terminal or a Java IDE

## How to Run

1. Download or clone this repository.
2. Open Terminal in the project folder.
3. Compile the program:

   `javac MovieTheatreTicketSystem.java`

4. Run the program:

   `java MovieTheatreTicketSystem`

## Limitations

This is a basic educational project. Data is stored in memory and is lost when the program exits. It does not use a database or real payment gateway.
